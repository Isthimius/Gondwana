Detailed Description

Provides a passive touch/pointer state adapter for Avalonia applications, implementing ITouchAdapter by translating Avalonia PointerPressed, PointerMoved, PointerReleased, and PointerCaptureLost events into Gondwana touch state. Events are not raised directly; the TouchEventPoller polls this adapter each engine frame to detect transitions and raise events.

On physical touch devices (Android, iOS), each finger contact is tracked by Avalonia's pointer ID and exposed as a unique TouchPoint. On desktop platforms where no hardware touch screen is present, mouse pointer events are emulated as a single touch point with Id = 0.

Dispose this adapter to unsubscribe from all Avalonia pointer events.

Drains and returns all touch contacts that ended (lifted or cancelled) since the last call. Each entry preserves the original TouchPhase (TouchPhase.Ended or TouchPhase.Cancelled) so the poller can distinguish between the two. This method is intended to be called once per engine tick by the TouchEventPoller.
