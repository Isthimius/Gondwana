Detailed Description

Represents an adapter for keyboard input, providing access to the currently pressed keys and active modifier states.

This interface is designed to abstract keyboard input handling, allowing retrieval of pressed keys and modifier states. The implementation of the interface is responsible for keyboard polling, etc.
