Detailed Description

Provides a bitmap (CPU) render surface adapter for Blazor that presents each frame by converting pixel data from a SKImage into an RGBA byte array and drawing it onto the HTML canvas element owned by BlazorBitmapRenderSurfaceComponent.

This approach works in Blazor WebAssembly without requiring platform-specific SkiaSharp view packages. Each frame the engine produces is read into a managed RGBA byte array and then transferred to the browser canvas via the gondwana-blazor.js JS module.
