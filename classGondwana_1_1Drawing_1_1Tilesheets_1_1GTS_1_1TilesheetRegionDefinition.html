Detailed Description

Defines a rectangular region within a tilesheet, including its location, tile dimensions, and spacing parameters.

A tilesheet can contain multiple regions, each representing a distinct grid of tiles with its own layout parameters. This class encapsulates all the information needed to correctly parse and extract individual tiles from a region.
