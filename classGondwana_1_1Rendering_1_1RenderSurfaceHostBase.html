Gondwana Game Engine v2.3.0
Gondwana is a cross-platform 2.5D game and rendering engine written in C#/.NET 8. It provides fine-grained control over rendering, timing, and scene composition, with built-in support for parallax, z-ordering, pixel overhang, collision detection, and particle effects. Gondwana targets desktop, mobile, and web platforms using SkiaSharp for graphics and NAudio for sound.

void Gondwana.Rendering.RenderSurfaceHostBase.Dispose ( )

Releases all resources used by this RenderSurfaceHostBase instance.

This method unregisters the render surface host from the RenderSurfaceHostRegistry and releases any managed resources. Derived classes should override Dispose(bool) to release additional resources specific to their implementation.

After calling Dispose(), this instance should not be used. Calling Dispose() multiple times is safe and has no additional effect.

◆ GlRenderAndSnapshot()

SKImage? Gondwana.Rendering.RenderSurfaceHostBase.GlRenderAndSnapshot ( )

Renders the current scene frame on the GL thread and returns a snapshot of the GPU backbuffer ready to be drawn to the window surface.

This method is intended to be called from SKGLControl.PaintSurface (the GL thread) by a WinFormGpuRenderSurfaceAdapter that has been set as the host's adapter. It is the Option-A equivalent of the engine loop's RenderToBackbuffer + PresentBackbufferToAdapter pair; both operations happen synchronously on the GL thread, with no cross-thread posting.

The returned SKImage is a lightweight GPU-backed view of the backbuffer texture. The caller must dispose it after drawing (typically with a using statement), and must do so within the same PaintSurface call to avoid aliasing with the next frame's rendering pass.

Returns null when BackbufferBase.IsGlThreadRendered is false (i.e. this is not a GPU-rendered surface).

Returns
A GPU-backed SKImage snapshot of the rendered frame, or null if this surface does not use GL-thread rendering.
