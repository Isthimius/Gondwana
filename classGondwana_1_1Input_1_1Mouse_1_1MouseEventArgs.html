Detailed Description

Provides comprehensive data for mouse events, including cursor position (current and previous), button states with transition information, scroll wheel delta, and keyboard modifier states. This event args class is used with mouse input polling to deliver complete mouse state information to event handlers, enabling sophisticated mouse interaction handling including drag operations, modified clicks, and scroll detection.

Determines whether the specified mouse button is currently in the down (pressed) state.

Parameters
buttonThe mouse button to evaluate.
Returns
true if the specified button is currently pressed; otherwise, false. Returns false if the button is not present in the tracked state collection.

This method provides a safe and convenient way to query button state without directly accessing the ButtonStates dictionary. It avoids exceptions that could occur if a button is not present and centralizes lookup logic.
