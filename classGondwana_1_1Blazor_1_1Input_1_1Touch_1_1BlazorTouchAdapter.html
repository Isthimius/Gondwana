Detailed Description

Provides a passive touch state adapter for Blazor applications, implementing ITouchAdapter by translating Blazor ontouchstart, ontouchmove, ontouchend, and ontouchcancel events into Gondwana touch state.

Events are not raised directly; the TouchEventPoller polls this adapter each engine frame to detect transitions and raise events.

On touch-capable devices each finger contact is tracked by its browser touch identifier. On desktop platforms where touch events are not available, use the mouse adapter for pointer input.

IReadOnlyList< GondwanaTouchPoint > Gondwana.Blazor.Input.Touch.BlazorTouchAdapter.ConsumeEndedTouches ( )

Drains and returns all touch contacts that ended (lifted or cancelled) since the last call. Each entry preserves the original TouchPhase (TouchPhase.Ended or TouchPhase.Cancelled) so the poller can distinguish between the two. This method is intended to be called once per engine tick by the TouchEventPoller.

Returns
A snapshot of all contacts that ended since the previous call to this method. The returned list is cleared from the adapter's internal queue on each call.
