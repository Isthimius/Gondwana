enum Gondwana.Movement.Easing.EasingKind

All supported easing functions. Each function expects t ∈ [0,1] and returns a smoothed [0,1].

Enumerator
Linear 

Linear easing; no acceleration or deceleration.

EaseInQuad 

Quadratic ease-in; starts slowly and accelerates.

EaseOutQuad 

Quadratic ease-out; starts quickly and decelerates.

EaseInOutQuad 

Quadratic ease-in/out; slow start and end, fast middle.

EaseInCubic 

Cubic ease-in; starts very slowly, strong acceleration.

EaseOutCubic 

Cubic ease-out; starts quickly, strong deceleration.

EaseInOutCubic 

Cubic ease-in/out; gentle start and finish, smooth center.

EaseInQuart 

Quartic ease-in; very slow start with steep acceleration.

EaseOutQuart 

Quartic ease-out; fast start with steep deceleration.

EaseInOutQuart 

Quartic ease-in/out; balanced acceleration and deceleration.

EaseInQuint 

Quintic ease-in; extremely slow start with powerful acceleration.

EaseOutQuint 

Quintic ease-out; very fast start with strong deceleration.

EaseInOutQuint 

Quintic ease-in/out; smoothest ease with a flat midpoint.

SmoothStep 

SmoothStep; Hermite interpolation (3t² - 2t³), smooth edges.

SmootherStep 

SmootherStep; improved Hermite interpolation (6t⁵ - 15t⁴ + 10t³) with gentler transitions.
