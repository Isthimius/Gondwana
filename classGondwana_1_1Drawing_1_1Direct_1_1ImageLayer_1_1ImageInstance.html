Detailed Description

Represents a single image instance rendered by an ImageInstanceLayer.

An image instance is a lightweight visual object consisting of a bitmap, bounds, optional velocity, optional rotation, and tint.

This type is intended for larger, longer-lived visual elements such as drifting clouds, fog patches, leaves, embers, or similar ambient image-based effects.
