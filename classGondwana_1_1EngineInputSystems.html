Gondwana Game Engine v2.5.0
Gondwana is a cross-platform 2.5D game and rendering engine written in C#/.NET 8. It provides fine-grained control over rendering, timing, and scene composition, with built-in support for parallax, z-ordering, pixel overhang, collision detection, and particle effects. Gondwana targets desktop, mobile, and web platforms using SkiaSharp for graphics and NAudio for sound.

ITouchAdapter? Gondwana.EngineInputSystems.TouchAdapter

Gets or sets the touch adapter responsible for providing raw touch state to the engine.

Setting this property disposes the previous adapter (if it implements IDisposable) and initializes a new TouchEventPoller instance backed by the supplied adapter. Pass null to clear the current adapter without replacing it.

TouchEventPoller? Gondwana.EngineInputSystems.TouchEventPoller
get

Gets the touch event polling subsystem, if initialized.

The Gondwana.Input.Touch.TouchEventPoller instance if initialized; otherwise, null.

This property provides access to the touch input subsystem, which also implements ITouchInput for gesture recognizer consumption. Initialize it by assigning a platform adapter to TouchAdapter, or by calling engine.InitializeAvaloniaTouchAdapter(control) from the Gondwana.Avalonia package.
