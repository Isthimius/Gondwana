# Gondwana Game Engine Plugin Terms

Last updated: August 22, 2026

These terms cover use of the public Gondwana Game Engine plugin and its read-only Gondwana MCP service.

## Purpose

The plugin helps users build, debug, and understand software that uses the Gondwana Game Engine. Its MCP service exposes read-only access to the public `Isthimius/Gondwana` repository and Gondwana GitHub wiki.

## No repository write access

The Gondwana MCP service does not create commits, branches, issues, pull requests, releases, or other GitHub changes. It does not provide arbitrary-repository access.

A host product such as Codex may separately be able to edit files in a user's own local workspace when the user asks it to do so. Those local editing capabilities are provided by the host product, not by the Gondwana MCP service.

## Acceptable use

Use the plugin lawfully and in accordance with the terms and policies of OpenAI, GitHub, Render, and any other services involved in your workflow.

Do not attempt to use the service to obtain secrets, bypass access controls, overload the service, or redirect it to repositories or systems outside its intended Gondwana scope.

## Accuracy

The plugin is designed to ground answers in current Gondwana source, tests, demos, templates, and documentation, but generated explanations and code can still contain mistakes. Review and test generated code before relying on it.

## Availability and changes

The plugin and MCP service may be changed, rate-limited, temporarily unavailable, moved to a different hosting provider, or discontinued. No service-level agreement is provided.
