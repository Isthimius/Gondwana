# Gondwana Game Engine Plugin Support

For help with the Gondwana Game Engine plugin or its MCP service:

- **Usage questions:** use the Gondwana GitHub Discussions **Q&A** category.
- **Reproducible plugin/MCP bugs:** open a GitHub issue in `Isthimius/Gondwana`.
- **Engine design ideas:** use the Gondwana GitHub Discussions **Ideas** category.

Repository:

`https://github.com/Isthimius/Gondwana`

Q&A:

`https://github.com/Isthimius/Gondwana/discussions/categories/q-a`

Issues:

`https://github.com/Isthimius/Gondwana/issues`

When reporting a plugin or MCP problem, include the affected tool or skill, the user prompt or command, the expected result, the actual result, and any non-sensitive error text.

Do not post passwords, GitHub tokens, OpenAI credentials, private source code, or other secrets in a public issue or discussion.
