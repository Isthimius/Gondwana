Detailed Description

Provides a GPU-accelerated render surface adapter for Windows Forms using OpenGL and SKGLControl.

All scene rendering and presentation are driven from within PaintSurface on the GL thread Invalidate() is posted to the UI thread via Engine.UiDispatcher at the end of each Engine.DoForegroundTasks cycle (via Engine.AfterFrameRender), so the paint loop stays in lockstep with the engine's own frame rate. The engine's background render loop skips GPU-rendered surfaces entirely (see GpuBackbuffer.IsGlThreadRendered).

◆ SetHost()

void Gondwana.WinForms.Rendering.WinFormGpuRenderSurfaceAdapter.SetHost ( RenderSurfaceHostBase  host)

Registers the RenderSurfaceHostBase whose scene this adapter should render and wires the GL paint loop to the engine's foreground cycle.

After this call all rendering is driven from PaintSurface on the GL thread. Invalidate() is posted to the UI thread via Engine.UiDispatcher at the end of each Engine.DoForegroundTasks call (via Engine.AfterFrameRender), so the frame rate is governed entirely by Gondwana.Configuration.EngineConfiguration.TargetFPS.

Parameters
hostThe render surface host to render each frame.
