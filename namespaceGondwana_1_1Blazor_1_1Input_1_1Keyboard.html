enum Gondwana.Blazor.Input.Keyboard.BlazorKey

Maps browser KeyboardEvent.code values to stable integer key codes used by BlazorKeyboardAdapter and the Gondwana KeyboardEventPoller.

Enum member names exactly match the browser KeyboardEvent.code strings (e.g. KeyA, ArrowLeft, Space) so that Enum.TryParse<T> can be used to convert browser codes directly to key codes without an explicit lookup table. Pass a member name or its integer value to KeyboardEventPoller.StartMonitoringKey.
