# Rage to Pro

A tiny management game about grinding on a terrible PC without destroying the room.

- Every real-time second completes one in-game hour and earns money.
- Random lag spikes add rage; reaching 100% breaks an item and charges a repair bill.
- Pausing cools rage, while four sequential shop upgrades improve income and reduce rage gain.
- Install the Pro Stream Rig to complete the progression goal.

Controls: `Space` plays or pauses, `1`–`4` buy upgrades, `R` resets, and `Esc` quits. The play and shop buttons also accept mouse clicks.

Run with:

```console
dotnet run --project Demos/Gondwana.RageToPro/Gondwana.RageToPro.csproj
```
