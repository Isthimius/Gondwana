# The Great Plop

A compact, code-drawn Gondwana game prototype about pressure, pasture logistics, and questionable agricultural automation.

## Play

- Move with **WASD** or the arrow keys.
- Hold **Space** or the large dashboard button to build pressure; release to create inventory.
- Release in the purple **Titanic** zone for the largest payout. Holding too long causes a three-second blowout.
- Physically push piles into the sell chute at the upper-left. Selling several together awards a combo multiplier.
- Buy upgrades with **1–6**. The beetle assistant automates delivery.
- Press **R** to reset and **Escape** to quit.

All art is drawn at runtime with SkiaSharp, so the demo has no external asset dependency.
