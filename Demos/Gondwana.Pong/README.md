# Gondwana Pong

An asset-free Pong demo built with Gondwana's WinForms bitmap host.

## Controls

- **W / S** — Player 1
- **Up / Down** — Player 2 when two-player mode is active
- **Tab** — toggle the right paddle between CPU and Player 2
- **Space** — serve
- **R** — restart
- **Escape** — quit

The first player to seven points wins. Run from the repository root:

```console
dotnet run --project Demos/Gondwana.Pong/Gondwana.Pong.csproj
```
