Detailed Description

A platform-agnostic splash screen implemented as a DirectImage overlay on the primary render surface, animated with the engine's built-in DirectDrawingBase.FadeIn and DirectDrawingBase.FadeOut transitions.

Create an instance via TryCreate after calling GameHostBase.InitializeAsync—the engine must already be running so the animation loop can drive the fade. Call ShowAsync to fade the splash in (and hold it), then HideAsync to fade it out. Dispose the instance when done to release the underlying image resources.

The overlay is rendered in view-space with int.MaxValue Z-order so it always appears on top of other direct drawings.
