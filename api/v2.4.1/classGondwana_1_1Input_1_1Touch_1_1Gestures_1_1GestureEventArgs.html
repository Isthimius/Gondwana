Detailed Description

Provides data for the TouchEventPoller.TouchEvent, carrying the details of a recognized gesture. Check IsTap, IsSwipe, or IsPinch to determine which kind of gesture occurred, then access the corresponding nullable property (Tap, Swipe, or Pinch) for the specific data.

This follows the same pattern as MouseEventArgs: a single unified event type whose properties make it easy to filter and act on specific interaction kinds. For example:

engine.Input.TouchEventPoller.TouchEvent += e =>
{
if (e.IsTap) HandleTap(e.Tap!);
if (e.IsSwipe) HandleSwipe(e.Swipe!);
if (e.IsPinch) HandlePinch(e.Pinch!);
};
