Detailed Description

Represents a touch input source that tracks active contact points and raises lifecycle events when fingers (or pointer-emulated contacts) begin, move, or end on a surface.

Implementations of this interface are responsible for translating platform-specific pointer or touch events into Gondwana TouchPoint values and maintaining the ActiveTouches collection. On desktop platforms where no hardware touch screen is available, adapters may emulate a single touch point using the mouse cursor.
