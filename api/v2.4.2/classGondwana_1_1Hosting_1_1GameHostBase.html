Gondwana Game Engine Version 2.4.2
Gondwana is a cross-platform 2.5D game and rendering engine written in C#/.NET 8. It provides fine-grained control over rendering, timing, and scene composition, with built-in support for parallax, z-ordering, pixel overhang, collision detection, and particle effects. Gondwana targets desktop, mobile, and web platforms using SkiaSharp for graphics and NAudio for sound.

◆ InitializeAsync()

async Task Gondwana.Hosting.GameHostBase.InitializeAsync ( string? configPath = null,
bool? autoSaveConfig = null,
LogLevel logLevel = LogLevel::Warning )

Initializes the game host, then shows a Gondwana-native splash screen (if one is provided by CreateSplash) that fades in, holds, and fades out over the running game.

Parameters
configPathOptional path to the configuration file.
autoSaveConfigOptional flag indicating whether to automatically save configuration changes.
logLevelThe log level to use for engine logging. Default is LogLevel.Warning.

Initialization is performed synchronously (identical to Initialize), after which the engine is already running. The splash is then created—as a Gondwana.Drawing.Direct.DirectImage overlay on the primary render surface—and animated using the engine's own fade system, making it fully platform-agnostic and reusable across projects.

Override CreateSplash in a subclass to provide a custom splash image and to configure SplashScreen.AfterFadeInAsync for startup work that should run after fade-in completes.

Override GetPrimaryRenderSurfaceHost in platform-specific subclasses to expose the render surface host that the splash will be attached to.
