Detailed Description

Manages audio playback in browser/WASM environments using the HTML5 Audio API.

Use this manager instead of AudioResourceManager when running on a net8.0-browser target. It routes all audio operations to the gondwana-audio JavaScript module rather than the NAudio-based desktop pipeline (which is unavailable in WebAssembly).

Access the singleton instance through the engine extension method:

var mgr = Engine.Instance.GetBrowserAudioManager();

Loads an audio file and returns a BrowserAudioPlayer that controls it.

If a player with the same key already exists it is stopped and replaced. The src should be a URL relative to the application root (e.g. "assets/theme.mp3").
