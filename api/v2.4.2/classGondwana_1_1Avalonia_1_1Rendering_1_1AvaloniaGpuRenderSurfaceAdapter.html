Detailed Description

Provides a GPU-accelerated render surface adapter for Avalonia, backed by global::Avalonia.OpenGL.Controls.OpenGlControlBase.

The adapter's primary role is to track the physical-pixel dimensions of the render target (consumed by RenderSurfaceHost<T> when computing the scene viewport) and to post RequestNextFrameRendering() to the UI thread after each engine foreground cycle. All actual GL operations — surface creation, rendering, and presentation — are handled by AvaloniaGpuRenderSurfaceControl.

VSync: The GpuBackbuffer.VSync property has no effect when used with this adapter; swap-interval control is delegated to Avalonia's compositor.

Platform support: Requires a GPU-capable Avalonia backend (Windows/macOS/Linux desktop). Not suitable for WebAssembly (WASM) targets; use AvaloniaBitmapRenderSurfaceAdapter for cross-platform / WASM scenarios.
