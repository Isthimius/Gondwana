Detailed Description

Opt-in, bounded runtime measurements independent of legacy CPS notifications.

Queries are non-consuming. Producers take a short lock; no callbacks run inside it. A completed bucket is published on the next observation or query after the interval expires. Empty time spans form one idle bucket instead of an unbounded catch-up sequence.
