Detailed Description

Keyboard adapter for Blazor applications that feeds the Gondwana KeyboardEventPoller by translating browser KeyboardEvent.code values into BlazorKey integer codes.

Key codes correspond to BlazorKey values cast to int. Use GetKeyCodeFromString to resolve a key name at runtime, or use (int)BlazorKey.Space directly in game code.

Keyboard events are captured on the canvas element owned by BlazorBitmapRenderSurfaceComponent. The canvas must have focus for events to be received; the component requests focus automatically on first render.
