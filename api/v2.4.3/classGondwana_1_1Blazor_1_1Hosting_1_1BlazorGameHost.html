Gondwana Game Engine Version 2.4.3
Gondwana is a cross-platform 2.5D game and rendering engine written in C#/.NET 8. It provides fine-grained control over rendering, timing, and scene composition, with built-in support for parallax, z-ordering, pixel overhang, collision detection, and particle effects. Gondwana targets desktop, mobile, and web platforms using SkiaSharp for graphics and NAudio for sound.

Detailed Description

Provides a base class for hosting Gondwana games in Blazor WebAssembly applications.

On browser/WASM targets the engine runs in timer-driven mode via PeriodicTimer, because Blazor WebAssembly does not support background threads. The timer targets 60 frames per second by default. On non-browser targets (e.g. Blazor Server) the standard background- thread engine loop is used.

Usage: derive from this class, override GameHostBase.CreateInitialScene, GameHostBase.CreateSprites, etc., then construct your subclass with the BlazorBitmapRenderSurfaceComponent instance from your Blazor page and call GameHostBase.Initialize.
