Detailed Description

Recognizes two-finger pinch and spread gestures by listening to touch events from an ITouchInput source. Raises PinchUpdated each time the distance between the two active contact points changes, providing a relative scale delta.

Subscribe to the PinchUpdated event to receive incremental scale updates as the user moves two fingers together or apart. A PinchedEventArgs.ScaleDelta greater than 1.0 means the fingers spread apart (expand), while a value less than 1.0 means they moved closer (contract).

All simultaneous contacts are tracked. Pinch updates are emitted only when exactly two contacts are active. If a third finger lands while two are tracked, updates pause until one lifts and exactly two remain — at which point the baseline distance is recomputed so there is no jump.
