Detailed Description

Coordinates Gondwana foreground-frame requests with a Blazor WebGL render surface.

The SKGLView owns the browser animation loop. This adapter therefore does not request another browser frame when the engine completes a foreground update; it only records that a new scene frame is due. The active SKGLView paint callback consumes that request and renders the scene immediately while the WebGL context is current.
