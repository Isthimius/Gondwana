Gondwana Game Engine Development (master) - 2.7.0
Gondwana is a cross-platform 2.5D game and rendering engine written in C#/.NET 8. It provides fine-grained control over rendering, timing, and scene composition, with built-in support for parallax, z-ordering, pixel overhang, collision detection, and particle effects. Gondwana targets desktop and web platforms using SkiaSharp for graphics and pluggable audio backends for desktop and browser targets.

479 private static Rectangle GetBodyBounds(Rectangle bounds)
480 {
481 int top = bounds.Y + SpeakerHeight + 4;
482 int bottom = bounds.Bottom - ContinueIndicatorHeight - 4;
483
484 return new Rectangle(
485 bounds.X + ContentInset,
486 top,
487 Math.Max(1, bounds.Width - ContentInset * 2),
488 Math.Max(1, bottom - top));
489 }
490
491 private static Rectangle GetContinueBounds(Rectangle bounds)
492 {
493 return new Rectangle(
494 bounds.Right - ContentInset - ContinueIndicatorWidth,
495 bounds.Bottom - ContinueIndicatorHeight - 4,
496 ContinueIndicatorWidth,
497 ContinueIndicatorHeight);
498 }
