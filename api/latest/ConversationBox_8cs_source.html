Gondwana Game Engine Development (master) - 2.6.0
Gondwana is a cross-platform 2.5D game and rendering engine written in C#/.NET 8. It provides fine-grained control over rendering, timing, and scene composition, with built-in support for parallax, z-ordering, pixel overhang, collision detection, and particle effects. Gondwana targets desktop, mobile, and web platforms using SkiaSharp for graphics and NAudio for sound.

368 private static Rectangle GetBodyBounds(Rectangle bounds)
369 {
370 int top = bounds.Y + SpeakerHeight + 4;
371 int bottom = bounds.Bottom - ContinueIndicatorHeight - 4;
372 return new Rectangle(bounds.X + ContentInset,
373 top,
374 Math.Max(1, bounds.Width - ContentInset * 2),
375 Math.Max(1, bottom - top));
376 }
377
378 private static Rectangle GetContinueBounds(Rectangle bounds)
379 {
380 return new Rectangle(bounds.Right - ContentInset - ContinueIndicatorWidth,
381 bounds.Bottom - ContinueIndicatorHeight - 4,

383 ContinueIndicatorHeight);
384 }
