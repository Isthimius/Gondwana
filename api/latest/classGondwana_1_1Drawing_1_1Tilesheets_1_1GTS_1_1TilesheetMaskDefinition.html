Detailed Description

Defines a color mask used to identify and process specific colors within a tilesheet image.

The mask uses RGBA color components with a tolerance value to match colors within a specified range. This is commonly used for transparency masking, color keying, or identifying specific tile boundaries.

◆ Tolerance

byte Gondwana.Drawing.Tilesheets.GTS.TilesheetMaskDefinition.Tolerance = 5
getset

Gets or sets the tolerance value for color matching, allowing colors within a range to be considered matching.

Defaults to 5. Higher values allow more variation in color matching.

A tolerance of 0 requires exact color matches, while higher values allow colors within the specified range to match. For example, a tolerance of 5 would match colors where each component (R, G, B, A) differs by no more than 5 from the mask color.
