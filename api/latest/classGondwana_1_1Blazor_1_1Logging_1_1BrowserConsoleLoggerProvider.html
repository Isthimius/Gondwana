Detailed Description

Writes Microsoft.Extensions.Logging records to the browser developer console without using the desktop-oriented Microsoft console logging provider.

Browser-hosted Gondwana games normally route records through EngineLogger, so asynchronous engine logging still performs queueing before this provider is invoked.

The implementation uses Console.Out and Console.Error. In WebAssembly these streams are bridged by the .NET browser runtime to the browser developer console without requiring explicit JavaScript interop.
