Detailed Description

A Blazor component that presents Gondwana game frames on an HTML <canvas> element and forwards keyboard, mouse, and touch events to the Gondwana input adapters.

Place this component anywhere in your Blazor page layout and pass the instance to BlazorGameHost (from Gondwana.Blazor.Hosting) to wire up the engine lifecycle.

The component must be visible in the DOM before Initialize is called on the host, because rendering is initiated during OnAfterRenderAsync on the first render.

Keyboard events require the canvas to have focus. The component requests focus automatically on first render; games may also call element.focus() from JavaScript as needed.
