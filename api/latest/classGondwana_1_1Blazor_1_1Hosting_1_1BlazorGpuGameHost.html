Detailed Description

Provides a base class for Gondwana Blazor games rendered through WebGL and Gondwana.Rendering.Backbuffers.GpuBackbuffer.

In browser/WASM builds, the BlazorGpuRenderSurfaceComponent owns the browser animation loop through SKGLView. Its paint callback advances the timer-driven engine and presents the GPU frame in the same browser animation-frame callback.
