Gondwana Game Engine Development (master) - 2.6.0
Gondwana is a cross-platform 2.5D game and rendering engine written in C#/.NET 8. It provides fine-grained control over rendering, timing, and scene composition, with built-in support for parallax, z-ordering, pixel overhang, collision detection, and particle effects. Gondwana targets desktop, mobile, and web platforms using SkiaSharp for graphics and NAudio for sound.

271 private static Rectangle ResolveBounds(View view, Rectangle? bounds)
272 {
273 ArgumentNullException.ThrowIfNull(view);
274
275 if (bounds is not null)
276 return bounds.Value;
277
278 Rectangle viewport = view.Viewport.TargetRectPx;
279
280 int availableWidth = Math.Max(1, viewport.Width - 40);
281 int availableHeight = Math.Max(1, viewport.Height - 40);
282 int width = Math.Min(DefaultWidth, availableWidth);
283 int height = Math.Min(DefaultHeight, availableHeight);
284
285 return new Rectangle(viewport.Left + (viewport.Width - width) / 2,
286 viewport.Top + (viewport.Height - height) / 2,
287 width,
288 height);
