Gondwana Game Engine Development (master) - 2.7.0
Gondwana is a cross-platform 2.5D game and rendering engine written in C#/.NET 8. It provides fine-grained control over rendering, timing, and scene composition, with built-in support for parallax, z-ordering, pixel overhang, collision detection, and particle effects. Gondwana targets desktop and web platforms using SkiaSharp for graphics and pluggable audio backends for desktop and browser targets.

392 private int CreateGpuSurface(
393 GRContext grContext,
394 int width,
395 int height,
396 int requestedSampleCount)
397 {
398 // Rgba8888 / Premul is the natural format for an OpenGL render target.
399 var info = new SKImageInfo(
400 width,
401 height,
402 SKColorType.Rgba8888,
403 SKAlphaType.Premul);
404
405 _surface = SKSurface.Create(
406 grContext,
407 budgeted: true,
408 info,
409 requestedSampleCount);
410
411 if (_surface is not null)
412 return requestedSampleCount;
413
414 // SKSurface.Create returns null when the requested MSAA sample count is not supported
415 // by the hardware or driver. Fall back to no MSAA (sample count 1) so the surface
416 // is always valid after Initialize() completes.
417 if (requestedSampleCount > 1)
418 _surface = SKSurface.Create(
419 grContext,
420 budgeted: true,
421 info,
422 sampleCount: 1);
423
424 if (_surface is null)
425 throw new InvalidOperationException(
426 $"Failed to create a {nameof(GpuBackbuffer)} GPU surface ({width}x{height}). " +
427 "The GRContext may be invalid or the pixel format is not renderable.");
428
429 return 1;
430 }
