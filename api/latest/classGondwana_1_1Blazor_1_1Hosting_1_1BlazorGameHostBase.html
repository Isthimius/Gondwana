Detailed Description

Provides the shared Gondwana lifecycle integration for Blazor bitmap and WebGL game hosts.

Browser/WASM targets use timer-driven engine execution. Bitmap hosts are driven by Gondwana's JavaScript requestAnimationFrame loop, while WebGL hosts are driven directly by the SKGLView animation loop so engine advancement and GPU presentation share one browser animation-frame callback. Non-browser targets retain the standard background engine loop supplied by GameHostBase.

◆ RenderSurfaceDrivesBrowserFrames

virtual bool Gondwana.Blazor.Hosting.BlazorGameHostBase.RenderSurfaceDrivesBrowserFrames
getprotected

Gets a value indicating whether the render surface itself supplies the browser animation callback that drives the timer-driven engine.

The bitmap path returns false and uses Gondwana's JavaScript animation loop. The WebGL path returns true because SKGLView owns the browser requestAnimationFrame loop and calls Gondwana.Engine.Tick from its paint callback.
