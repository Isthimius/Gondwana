Detailed Description

Provides a passive touch state adapter for Blazor applications, implementing ITouchAdapter by translating Blazor ontouchstart, ontouchmove, ontouchend, and ontouchcancel events into Gondwana touch state.

Events are not raised directly; the TouchEventPoller polls this adapter each engine frame to detect transitions and raise events.

On touch-capable devices each finger contact is tracked by its browser touch identifier. On desktop platforms where touch events are not available, use the mouse adapter for pointer input.
