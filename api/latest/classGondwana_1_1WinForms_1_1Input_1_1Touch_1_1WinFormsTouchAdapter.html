Detailed Description

Captures native Windows touchscreen contacts (WM_TOUCH) from a WinForms render control and its child HWNDs for the standard Gondwana touch poller.

The UI thread records touch beginnings and endings, including contacts shorter than one engine frame. TouchEventPoller dispatches them on the engine thread. Mouse/pen input continues through the normal WinForms mouse adapter. Dispose on the WinForms thread, or let the engine dispose the touch poller.
