Gondwana is a cross-platform 2.5D game and rendering engine written in C#/.NET 8. It provides fine-grained control over rendering, timing, and scene composition, with built-in support for parallax, z-ordering, pixel overhang, collision detection, and particle effects. Gondwana targets desktop, mobile, and web platforms using SkiaSharp for graphics and NAudio for sound.

◆ GlRenderAndSnapshot()

SKImage? Gondwana.Rendering.RenderSurfaceHostBase.GlRenderAndSnapshot ( )

Renders the current scene frame on the active GL/WebGL thread and returns a snapshot of the GPU backbuffer ready to be drawn to the platform surface.

This method is intended to be called from the platform GPU paint callback while its GRContext is current. It is the GPU equivalent of the engine loop's RenderToBackbuffer + PresentBackbufferToAdapter pair; rendering and snapshot creation happen synchronously on the GPU-owning thread, with no CPU pixel transfer.

The returned SKImage is a lightweight GPU-backed view of the backbuffer texture. The caller must dispose it after drawing (typically with a using statement), and must do so within the same GPU paint callback to avoid aliasing with the next frame's rendering pass.

Returns null when BackbufferBase.IsGlThreadRendered is false (i.e. this is not a GPU-rendered surface).

Returns
A GPU-backed SKImage snapshot of the rendered frame, or null if this surface does not use GL-thread rendering.

◆ GlRenderToCanvas()

bool Gondwana.Rendering.RenderSurfaceHostBase.GlRenderToCanvas ( SKCanvas destinationCanvas)

Renders the current scene frame and draws the GPU backbuffer surface directly to another GPU canvas. Linear scaling uses a scoped GPU texture snapshot because direct surface drawing does not support sampling options. No CPU pixel transfer is performed.

Call only from the active GPU paint callback while both surfaces share the current GRContext. The destination is drawn at the origin using the destination canvas's current transform, followed by the adapter's aspect-preserving presentation transform.

Parameters
destinationCanvasThe active platform GPU canvas.
Returns
true when a GPU surface was rendered and drawn; otherwise false.

◆ GlSnapshotCurrentFrame()

SKImage? Gondwana.Rendering.RenderSurfaceHostBase.GlSnapshotCurrentFrame ( )

Returns a snapshot of the current GPU backbuffer without rendering a new scene frame.

This is intended for GPU presentation loops that run more frequently than Gondwana's configured foreground/render cadence. It allows the platform surface to re-blit the most recently rendered backbuffer while preserving Gondwana.Configuration.EngineConfiguration.TargetFPS.

Call only from the active GPU paint callback while the backbuffer's GRContext is current. The returned SKImage must be disposed before that callback returns.

Returns
A GPU-backed snapshot of the current backbuffer, or null when the surface does not use GL-thread rendering.
