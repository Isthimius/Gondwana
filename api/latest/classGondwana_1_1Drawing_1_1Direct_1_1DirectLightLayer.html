Detailed Description

Convenience owner for a group of scene-layer radial lights.

This is intentionally not a new SceneLayer type. Each light is still a bounded DirectRadialLight registered with DirectDrawingManager, so the existing scene-layer drawable query can include only lights whose world bounds intersect the dirty world rect.

Use this class when a game wants a clear logical owner for torch/lamp lights without changing the renderer's composition model.
