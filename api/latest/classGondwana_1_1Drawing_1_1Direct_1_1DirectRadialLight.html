Detailed Description

Draws a bounded, radial light effect as a scene-layer direct drawing.

DirectRadialLight is intended for localized draw-time lighting effects such as torches, lamps, spell glows, and other finite-radius light sources. It is deliberately modeled as a normal DirectDrawingBase instead of a post-process effect so it participates in Gondwana's existing dirty-rectangle selection path.

The important contract is its bounds: WorldBounds is the full world-space area that may be affected by the light. When a light moves or changes radius, both the old and new bounds are marked dirty by the inherited DirectDrawingBase.WorldBounds setter.

Rendering uses a Skia radial-gradient SKShader on an SKPaint. This keeps the first lighting primitive compatible with both bitmap and GPU-backed backbuffers while still exercising the same "shader during draw" idea that a later SkSL-backed implementation would use.

Event Documentation

◆ Changed

Action<DirectRadialLight>? Gondwana.Drawing.Direct.DirectRadialLight.Changed

Occurs when this light changes in a way tracked darkness overlays care about.

This event is primarily a synchronization hook for DirectDarknessOverlay and DirectSceneLayerDarknessOverlay. It is raised when the light's center, radius, base intensity, or effective flicker intensity changes. It is not intended to be a complete "any paint setting changed" notification for every cosmetic property.
