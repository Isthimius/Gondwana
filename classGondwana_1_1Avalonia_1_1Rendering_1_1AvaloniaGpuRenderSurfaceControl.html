Detailed Description

An Avalonia OpenGlControlBase that displays game frames produced by the Gondwana engine using GPU-accelerated rendering.

Rendering uses Avalonia's native OpenGL surface. SkiaSharp's GRContext is created from the current OpenGL context on the first render callback and is used to manage both the GpuBackbuffer off-screen surface and the window framebuffer blit. No CPU↔GPU pixel copies occur.

The engine's AfterFrameRender event posts RequestNextFrameRendering() to the UI thread to pace frame delivery in lockstep with Gondwana.Configuration.EngineConfiguration.TargetFPS.

This control targets desktop Avalonia platforms (Windows, macOS, Linux) that support OpenGL. Use AvaloniaBitmapRenderSurfaceControl for cross-platform / WASM scenarios instead.
