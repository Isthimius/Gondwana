Gondwana Game Engine v2.5.2
Gondwana is a cross-platform 2.5D game and rendering engine written in C#/.NET 8. It provides fine-grained control over rendering, timing, and scene composition, with built-in support for parallax, z-ordering, pixel overhang, collision detection, and particle effects. Gondwana targets desktop, mobile, and web platforms using SkiaSharp for graphics and NAudio for sound.

Detailed Description

Global WinForms key state collector that feeds the KeyboardHandler. Uses IMessageFilter so it sees ALL key messages (including arrows), regardless of which control has focus or how WinForms classifies them.

static ? Keys Gondwana.WinForms.Input.Keyboard.WinFormsKeyboardAdapter.GetKeyFromString ( string  keyName)
static

Attempts to convert a string representation of a key into its corresponding Keys value.

The comparison is case-insensitive. If the provided keyName does not match a valid Keys enumeration value, a warning is logged and null is returned.

Parameters
keyNameThe name of the key to parse. This should match a value from the Keys enumeration (e.g., "A", "Enter", "Escape").
Returns
A nullable Keys value representing the parsed key if successful; otherwise, null if the input string is not a valid key name.
