Detailed Description

Defines a passive adapter interface for accessing touch device state. Implementations update their internal state in response to platform events and expose that state for polling by TouchEventPoller. No events are raised directly from an adapter; all event routing is handled by the poller.

IReadOnlyList< TouchPoint > Gondwana.Input.Touch.ITouchAdapter.ConsumeEndedTouches ( )

Drains and returns all touch contacts that ended (lifted or cancelled) since the last call. Each entry preserves the original TouchPhase (TouchPhase.Ended or TouchPhase.Cancelled) so the poller can distinguish between the two. This method is intended to be called once per engine tick by the TouchEventPoller.

Returns
A snapshot of all contacts that ended since the previous call to this method. The returned list is cleared from the adapter's internal queue on each call.
